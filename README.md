# Project Meridian — anonymous ICRA 2027 project page

Static, dependency-free project-page scaffold for double-blind review.

## Before publishing

- Replace the placeholder title, abstract, metrics, and figure with paper content.
- Add `paper.pdf`, `supplementary.pdf`, and `code.zip` only when they are anonymized.
- Remove the Google Fonts import from `styles.css` if the page must have zero external requests; the system font fallbacks keep the layout usable.
- Do not link personal profiles, lab pages, non-anonymous repositories, or identifying videos.

The current page intentionally contains no analytics, cookies, or third-party embeds. The `noindex` metadata reduces accidental search exposure but is not a guarantee of anonymity.
